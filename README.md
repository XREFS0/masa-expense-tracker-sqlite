## Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/XREFS0/masa-expense-tracker-sqlite.git
   cd masa-expense-tracker-sqlite
   ```

2. **Set up virtual environment (optional but recommended)**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
   *(If `requirements.txt` is not provided, ensure required standard libraries or Django / Pillow / Tkinter are available)*

4. **Launch the application**:
   ```bash
   python main.py
   ```
